# skills/ 目录说明（本文件不注入 AI）

这里是 **AI 技能文档库**：服务端生成 AI 报告（复盘/规划/减量/对比）与直接对话时，
会把本目录下所有技能 Markdown 全文注入提示词的「专业知识库」段，
保证切换任意 AI 模型都能拿到一致的领域知识与撰写规范。

## 添加新技能

直接把 `.md` 文件放进本目录即可，无需改代码、无需重启服务（每次 AI 请求实时扫描）：

- 文件名即排序依据，建议 `NN-名称.md` 数字前缀控制注入顺序（如 `05-跑步训练.md`）；
- 文件首行的一级标题（`# 标题`）会作为该技能在提示词中的小节标题，缺失则用文件名；
- 空文件自动跳过；读取失败的文件仅警告跳过，不影响其它技能；
- 内容用中文撰写，聚焦"AI 解读数据时需要遵守的口径、阈值与标准"，避免重复
  提示词「指标口径与骑手参数」段已有的动态数值（那里反映当前骑手实际参数，优先级更高）。

## 规则

- `_` 开头的文件（如本文件）**不会**被注入，用于存放说明文档；
- 只识别 `.md` 扩展名；
- 内置技能（01–06）为训练科学标准口径整理（06 = 功率数据质量与校准），可直接编辑改进；
- 英文版用 `.en.md` 后缀（如 `06-power-data-quality.en.md`），lang=en 时加载；
- 目录路径可用环境变量 `FIT_SKILLS_DIR` 覆盖（测试隔离用）。

加载逻辑见 `src/skills.js`（`loadSkills` / `buildSkillsSection`），注入点为
`server.js`（四场景报告提示词 + chat 对话系统段；follow_up 追问不注入）。
