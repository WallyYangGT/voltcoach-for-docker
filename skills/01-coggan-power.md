# Coggan 功率训练体系

## 功率分区（7 级，按 %FTP）

| 分区 | 名称 | %FTP | 生理含义与典型用途 |
|---|---|---|---|
| Z1 | 主动恢复 | <55% | 促进血液循环、加速恢复，几乎不产生训练压力 |
| Z2 | 有氧耐力 | 56–75% | 有氧基础的主战场，可长时间维持，脂肪供能比例高 |
| Z3 | 节奏 | 76–90% | 甜区下沿，有氧与无氧交界，需一定恢复 |
| Z4 | 阈值 | 91–105% | 乳酸阈值附近，提升 FTP 的核心区间，单次可持续 10–60 分钟 |
| Z5 | VO2max | 106–120% | 最大摄氧量刺激，单组 3–8 分钟，显著提升有氧引擎上限 |
| Z6 | 无氧能力 | 121–150% | 无氧糖酵解供能，单组 30 秒–3 分钟，乳酸堆积明显 |
| Z7 | 神经肌肉 | >150% | 冲刺功率，持续 <30 秒，发展爆发力 |

解读分区时间分布时结合训练目的判断合理性：有氧耐力课应绝大部分落在 Z1–Z2；阈值课应有成块的 Z4 时间；若一次"轻松骑"有大量 Z4+ 时间，说明强度控制失败。注意统计口径：分区时间含 0W 秒（滑行与停车），Z1 占比高时先结合训练分类与场景（通勤/热身/恢复）判断，不要据此直接得出骑手「没有出力」的结论。

## 核心指标

- **NP（标准化功率）**：30 秒滚动平均的四次方均根。功率波动越大，NP 相对平均功率越高，反映"生理代价等效功率"。
- **VI（变异指数）= NP / 平均功率**：越接近 1 输出越平稳。平稳 TT/长距离骑行应 <1.05；>1.10 说明节奏混乱或路况起伏大。
- **IF（强度因子）= NP / FTP**：本次训练相对强度。参考标尺：<0.75 恢复/轻松；0.75–0.85 耐力；0.85–0.95 节奏/甜区；0.95–1.05 阈值；>1.05 接近全力（如比赛）。
- **TSS（训练压力分数）= 时长秒 × NP × IF / (FTP × 3600) × 100**：以"1 小时 FTP 输出 = 100 TSS"为锚的负荷量化。参考标尺：<150 低负荷（次日可完全恢复）；150–300 中等（次日有残余疲劳）；300–450 高负荷（需 2 天以上恢复）；>450 极高。

## 峰功率曲线解读

5s / 1min / 5min / 20min 四个锚点对应不同能力维度：5s 反映冲刺与神经肌肉能力；1min 反映无氧能力；5min 反映 VO2max；20min 反映阈值耐力。解读时看"短板"：若 5min 强而 20min 弱，提示阈值耐力不足、应加强甜区/阈值训练；反之则提示 VO2max 刺激不够。注意单次训练的峰功率受当日疲劳与战术影响，不宜仅凭一次下结论。

## FTP 估算

标准口径：20 分钟峰功率 × 0.95 ≈ FTP（Coggan 近似，假设 20 分钟全力约等于 60 分钟 FTP 的 105%）。局限：要求 20 分钟窗口是持续全力输出，日常训练中很少真正顶满，因此该估算通常偏保守（低估）；估算值仅供参考，不宜频繁据此上调 FTP。
